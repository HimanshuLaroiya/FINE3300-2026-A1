# FINE3300-2026-A1
USD/CAD Exchange Rate Convertor: This repository contains two versions of a USD/CAD exchange rate convertor. 

## Non-AI USD / CAD Exchange Rate Convertor 
This calculator takes the latest FX rate at 2025-01-01 from the Bank of Canada Exchange Rates and converts user USD dollar inputs into CAD dollars and vise vera, utilizing that FX rate. 

## AI USD / CAD Exchange Rate Convertor 
This calculator takes the latest FX rate from the Bank of Canada Exchange Rates and converts user USD dollar inputs into CAD dollars and vise vera, utilizing that FX rate.
